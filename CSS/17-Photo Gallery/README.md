# 🖼️ Project 17: Photo Gallery

A responsive image gallery application built with CSS Flexbox, demonstrating layout wrapping, aspect ratio management via `object-fit: cover`, and flex alignment techniques.

## 🛠️ Key Concepts Mastered

1. **Flexbox Multi-Line Layouts:**
   * Configured responsive image grids using `flex-direction: row`, `flex-wrap: wrap`, `justify-content: center`, and `gap` properties.

2. **Aspect Ratio & Image Fitting (`object-fit: cover`):**
   * Enforced uniform image box dimensions (`width`, `height`, `max-width`) while maintaining original aspect ratios using `object-fit: cover` to prevent visual distortion.

3. **Flexbox Alignment & Layout Balance:**
   * Utilized `align-items: center` along with pseudo-element spacers (`.gallery::after`) to align items evenly across dynamic viewport widths.
