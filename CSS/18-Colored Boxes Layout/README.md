# 🎨 Project 18: Colored Boxes Layout

A Flexbox layout project practicing flex item ordering (`order`), flex growth (`flex-grow`), flex shrinkage (`flex-shrink`), and container multi-line distribution using `align-content`.

## 🛠️ Key Concepts Mastered

1. **Flexbox Item Ordering (`order`):**
   * Reordered DOM elements visually without modifying HTML structure using numeric `order` properties across individual `.box` classes.

2. **Flex Sizing Mechanics (`flex-grow` & `flex-shrink`):**
   * Dynamically redistributed extra container space using `flex-grow: 1` on specific cards while controlling compression ratios via `flex-shrink: 3`.

3. **Multi-Line Axis Alignment (`align-content: space-evenly`):**
   * Evenly spaced flex lines along the cross-axis within a fixed-height container using `flex-wrap: wrap` and `align-content: space-evenly`.
