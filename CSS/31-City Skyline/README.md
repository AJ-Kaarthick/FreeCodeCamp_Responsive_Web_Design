# 🏙️ Project 31: City Skyline

A curriculum CSS project demonstrating modern CSS variables, multi-layered background graphics, CSS gradients, border-based geometric shapes, and theme-switching media queries.

## 🛠️ Key Architectural Concepts Mastered

1. **CSS Custom Properties (`:root` Variables):**
   * Centralized color palettes for building and window styling, allowing rapid global updates and theme adjustments.

2. **Advanced Gradients & Patterns:**
   * Utilized `linear-gradient()`, `radial-gradient()`, and `repeating-linear-gradient()` to create intricate architectural window textures, sky illumination, and building shading without external images.

3. **CSS Triangle & Polygon Shaping:**
   * Constructed custom building roofs and angled tops using clever combinations of transparent and solid border manipulations.

4. **Dynamic Dark Theme via Media Query:**
   * Overrode CSS root variables inside an `@media (max-width: 1000px)` query to automatically switch the skyline from a vibrant day/sunset theme to a monochromatic night mode.
