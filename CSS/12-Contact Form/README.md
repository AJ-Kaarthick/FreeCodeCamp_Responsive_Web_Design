# 📬 Project 12: Contact Form

An independent custom form application practicing accessible label bindings, HTML5 form validation, 45-degree linear gradients, centered typographical alignment, and pseudo-class hover effects.

## 🛠️ Key Concepts Mastered

1. **Accessible Form Label Binding:**
   * Linked `<label>` elements directly to target form controls (`#name`, `#email`, `#message`) using `for` and `id` references.

2. **Centered Typographical Alignment:**
   * Aligned form headers, input labels, typed field content, and submission triggers symmetrically using `text-align: center`.

3. **45-Degree Multi-Stop Gradients:**
   * Applied colorful 45-degree linear gradient backdrops across viewport and button elements (`linear-gradient(45deg, ...)`).
