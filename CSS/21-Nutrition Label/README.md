# 🥗 Project 21: Nutrition Label

An FDA-style nutrition facts label layout practicing typographic scale, custom dividers, line-height management, and pseudo-class selectors like `:not()`.

## 🛠️ Key Concepts Mastered

1. **Pseudo-class Selectors (`:not()`):**
   * Target elements conditionally using `.daily-value p:not(.no-divider)` to apply bottom borders selectively across complex text lists.

2. **Typography & Spatial Hierarchy:**
   * Controlled typography density using custom font weights (`font-weight: 800`), font scale conversions (`em`/`rem`), and negative margins (`margin: -5px -2px`) to match real-world print standards.

3. **Indentation & Alignment Rules:**
   * Used multi-level indentation classes (`.indent`, `.double-indent`) and negative text indentation (`text-indent: -8px`) to build footnote disclaimer styling.
