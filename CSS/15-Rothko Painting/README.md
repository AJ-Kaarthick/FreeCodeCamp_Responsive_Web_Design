# 🎨 Project 15: Rothko Painting

A CSS art project inspired by Mark Rothko's abstract expressionism, practicing box shadow spread values, element rotation, multi-value border radii, and Gaussian blur filters.

## 🛠️ Key Concepts Mastered

1. **CSS Visual Filters & Blurring (`filter: blur()`):**
   * Applied soft edge blending to canvas and color block elements to mimic organic paint bleeding.

2. **Asymmetrical Shapes & Transformations (`border-radius`, `transform`):**
   * Utilized multi-value `border-radius` syntax to construct asymmetrical geometric shapes.
   * Applied subtle rotation values (`rotate()`) to give color blocks an organic, hand-drawn canvas feel.

3. **Glow & Spread Effects (`box-shadow`):**
   * Layered soft ambient color glows using matching background and box-shadow color values with explicit spread radii.
