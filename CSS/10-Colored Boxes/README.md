# 🎨 Project 10: Colored Boxes

An independent CSS color system project practicing document background contrasts, fixed dimensional block boxes, and color representation syntax across Hexadecimal (`#HEX`), RGB (`rgb()`), Named Word Keywords, HSL (`hsl()`), and RGBA alpha channel definitions.

## 🛠️ Key Architectural Constraints Mastered

1. **Diverse CSS Color System Definitions:**
   * Implemented individual color syntax structures across class targets: Hexadecimal (`#1e3a8a`), functional RGB (`rgb(15, 118, 110)`), Keyword (`darkcyan`), HSL (`hsl(260, 60%, 45%)`), and RGBA (`rgba(...)`).

2. **Fixed Dimensional Bounds (`width` / `height`):**
   * Applied explicit pixel dimensions (`120px` x `120px`) on block items (`.color-box`) to guarantee layout visibility across viewport resizes.

3. **Flexbox Palette Layout Alignment:**
   * Organized palette swatches using flex container wrapping (`display: flex; flex-wrap: wrap; justify-content: center;`) with consistent gaps (`gap: 20px`).
