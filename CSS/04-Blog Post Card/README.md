# 📰 Project 04: Blog Post Card

An independent responsive CSS component practicing card layout architectures, background color layering, image fitting, border accents, and interactive action button state transitions.

## 🛠️ Key Architectural Constraints Mastered

1. **Card Layout & Background Layering:**
   * Structured a distinct background contrast between document root (`body { background-color: lavender; }`) and card container (`.blog-post-card { background-color: white; }`) with rounded boundary clipping (`border-radius: 12px; overflow: hidden;`).

2. **Image Fitting & Border Accents:**
   * Implemented relative image bounds (`width: 100%`) paired with `border-bottom` divider styling to isolate visual media from content text.

3. **Interactive Button Design (`inline-block`):**
   * Configured anchor elements into button UI blocks using `display: inline-block`, rounded margins/paddings, and dynamic `:hover` background color transitions.
