# 🎾 Project 24: Tribute Page (Roger Federer)

An independent responsive tribute page built using semantic HTML5 tags (`<main>`, `<figure>`, `<figcaption>`, `<blockquote>`) and layout-centering principles.

## 🛠️ Key Architectural Concepts Mastered

1. **Fluid Responsive Media:**
   * Styled images using `display: block`, `max-width: 100%`, and `height: auto` to maintain proper aspect ratio down to mobile screens.

2. **Block Centering Techniques:**
   * Utilized `margin: 0 auto` on block-level elements (`#image`, `#main`) alongside container-constrained max-widths.

3. **Semantic Figure Framing:**
   * Grouped illustrative content using `<figure id="img-div">` and `<figcaption id="img-caption">` for clean accessible page structure.
