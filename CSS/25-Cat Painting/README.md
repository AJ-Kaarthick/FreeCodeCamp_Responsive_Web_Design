# 🐱 Project 25: Cat Painting

A CSS illustration project practicing complex positioning, CSS border tricks for custom shapes, rotation transforms, and layered element stacking with `z-index`.

## 🛠️ Key Architectural Concepts Mastered

1. **CSS Border Shape Tricks:**
   * Built triangular shapes (ears, nose) using transparent left/right borders combined with solid bottom borders (`border-left: 35px solid transparent`, `border-bottom: 70px solid #5e5e5e`).

2. **Absolute Positioning & Transforms:**
   * Utilized `position: absolute` with precision offsets (`top`, `left`) and rotational shifts (`transform: rotate()`) to align complex facial features seamlessly.

3. **Layer Stacking & Pseudo-Curving:**
   * Managed element ordering using `z-index: 1` for ears and used selective border-color definitions (`border-color: black transparent transparent transparent`) with asymmetrical `border-radius` values to create curved mouth lines.
