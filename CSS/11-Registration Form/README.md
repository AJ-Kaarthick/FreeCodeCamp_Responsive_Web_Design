# 📋 Project 11: Registration Form

A comprehensive HTML5 form project demonstrating form structure, native validation, file uploads, radio/checkbox inputs, custom text areas, and themed control styling.

## 🛠️ Key Concepts Mastered

1. **Semantic Form Architecture:**
   * Grouped input fields using `<fieldset>` and `<legend>` elements to keep multi-part registration forms organized.
   * Bound labels directly to input controls using matching `for` and `id` attributes.

2. **Native HTML5 Validation & Inputs:**
   * Utilized diverse field types (`email`, `password`, `file`, `number`, `radio`, `checkbox`) with built-in constraints (`required`, `pattern`, `min`, `max`).

3. **Custom Control Styling:**
   * Overrode default browser styles on `<input>`, `<textarea>`, and `<select>` elements to create a dark theme (`#0a0a23` background with custom border accents).
   * Handled alignment for radio buttons and checkboxes using inline box utility resets (`width: unset`).
