# ⚡ Project 14: Feature Selection Page

An independent feature card selection component practicing custom checkbox styling (`appearance: none`), pseudo-element checkmark rendering (`::after`), left-aligned form layout symmetry, and CSS transition effects.

## 🛠️ Key Architectural Concepts Mastered

1. **Custom Checkbox UI Overrides (`appearance: none`):**
   * Overrode native checkbox browser styling using `appearance: none` to configure standard dimensions, custom emerald borders, and rounded corners.

2. **Pseudo-Element Checkmarks (`::after`):**
   * Generated checkmark icons inside checked inputs using `input[type="checkbox"]:checked::after` with Unicode character content (`✓`).

3. **Form Card Text Alignment:**
   * Aligned label text and checkboxes cleanly along the left margin (`text-align: left`) inside centered feature card containers to ensure consistent visual spacing.
