# 🐧 Project 38: CSS Penguin

An interactive CSS illustration project demonstrating custom CSS variables (`:root`), complex overlapping shape techniques, linear gradients, and keyframe-driven wave animations.

## 🛠️ Key Architectural Concepts Mastered

1. **Custom CSS Variables (`:root`):**
   * Defined centralized color themes (`--penguin-skin`, `--penguin-face`, `--penguin-picorna`) across complex nested elements.

2. **Advanced Shape Clipping & Positioning:**
   * Utilized asymmetric `border-radius` curves, `transform: skew()`, and `transform: rotate()` to build layered body parts, background mountains, and facial details.

3. **Keyframe Animation & Origin Scaling:**
   * Applied `@keyframes` wave motion to the left arm using `transform-origin: top left` and configured active state interactive scaling (`:active`).
